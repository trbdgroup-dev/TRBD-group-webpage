## Findings and fixes

| #   | Finding                                                                                                                         | Fix                                                                                                                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Q1  | The hero intro photo (the LCP element) was fetched at normal priority, alongside five tile images.                              | Intro image `loading="eager"` + `fetchPriority="high"` (Next 16 replaces `priority`); tiles `fetchPriority="low"`; the vertical-page graphic gets the same priority treatment.                             |
| Q2  | Source Serif 4 loaded with its optical-size axis: 147 KB of fonts.                                                              | Dropped the `opsz` axis, bringing fonts to 77 KB, with no visible difference at the sizes used.                                                                                                            |
| Q3  | Sentry's browser SDK (~42 KB gzip) sat in the main bundle.                                                                      | Now loads only after the page has loaded and the browser is idle, and only when a DSN is set. Up-front scripts dropped from 232 KB to 187 KB gzip. Trade-off: browser errors before it loads aren't reported (error pages load it on demand). |
| Q4  | The live-preview library (13 KB gzip) was downloaded by every visitor, though only the draft-mode preview bar uses it.          | Loaded with `next/dynamic` inside `PreviewBar`, so only staff in draft mode fetch it. Live Preview re-verified.                                                                                          |
| Q5  | The staff preview test was flaky when the desktop and phone runs logged in at the same moment (Payload keeps only one of the two sessions). | Playwright global setup logs in once and shares the session (`playwright/.auth/`, gitignored).                                                                                           |
| Q6  | Header logo: the visible text "TRBD" wasn't part of the link's accessible name (WCAG 2.5.3 Label in Name).                      | The mark's letters now come from CSS, and the accessible name "TRBD Consulting Group home" matches the visible company name.                                                                               |
| Q7  | Build warning: importing `withSentryConfig` from `@sentry/nextjs` is deprecated.                                                | Now imported from `@sentry/nextjs/config`.                                                                                                                                                                 |

## Coverage gaps carried forward

- The page-level `error.tsx` is only unit-tested. Rendering it in a production build would need a test-only route, which isn't worth adding.
- The production branch of `robots.txt` is only unit-tested; the launch checklist checks it on the live site.
- End-to-end tests run in Chromium only, not Safari/WebKit or Firefox. Add WebKit to Playwright once the site is live, especially if analytics show a meaningful share of iPhone visitors (likely).
- There are no real-device or real-network performance numbers until the site runs on Vercel.
